# 辨证卡

**前置**：红旗分诊已通过；症状信息已采集（否则先走 `nhx-consult`）。

## 输出结构

固定八段，用 GenUI 渲染：

````
```dsh-ui
{"title":"辨证卡","gap":12,"items":[
  {"type":"keyvalue","items":[["主诉归纳","..."],["辨证框架","八纲 / 六经 / 脏腑"],["证型倾向","..."],["置信度","倾向权重 0.0–1.0"]]},
  {"type":"list","title":"支持证据","items":["..."]},
  {"type":"list","title":"反对证据","items":["..."]},
  {"type":"list","title":"待确认项","items":["..."]},
  {"type":"list","title":"鉴别要点","items":["..."]},
  {"type":"keyvalue","title":"经典依据","items":[["《伤寒论》第 N 条","原文逐字"]]},
  {"type":"callout","variant":"warning","title":"就医建议","content":"..."}
]}
```
````

## 硬性要求

### 1. 语言：用「倾向」，不用「确诊」（红线 R3）

| ❌ 禁用 | ✅ 使用 |
|---|---|
| 你是 XX 证 | 倾向于 XX 证 |
| 你有 XX 病 | 现有信息提示 XX 的可能 |
| 确诊为 | 支持 / 反对证据如下 |

### 2. 证据必须分层

- **支持证据**：从用户自述里逐条对应
- **反对证据**：**不得为空**——至少写出 1 条「不支持该证型的观察」。
  只列支持证据是确认偏误，不是辨证。
- **待确认项**：需要面诊、舌诊、脉诊才能定的部分

### 3. 鉴别要点至少 1 组

写出最易混淆的相邻证型 + **怎么区分**。例：
> 少阳证 vs 肝火上炎：前者有往来寒热、脉弦，后者以目赤、头痛、脉弦数为主。

### 4. 经典依据逐字取自原文

条文号与原文从 `knowledge/01-人纪-中医经典/<科目>/原文/` 取出（红线 R1）。
**取不到就不写这条依据**，不要凭记忆补。

### 5. 就医建议必带

写清：建议就诊科室 + 需向医生说明的要点。不做确诊、不给方剂。

### 6. 置信度是倾向权重，不是概率

用 0.0–1.0 表示相对倾向强弱，**在输出中说明这一点**，避免用户误读为确诊概率。

## 完成判据

- 八段齐全，**反对证据与鉴别要点均非空**。
- 每条实质结论带来源标记（可溯源率目标 > 95%）。
- 全文无「你是/你有 XX 病」式断言。
- 结尾附 L2 合规定语。
- 未出现方名？——出现了也**不给剂量**（红线 R2）。
