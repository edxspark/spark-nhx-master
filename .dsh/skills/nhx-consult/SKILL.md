### 2. 补充采集（可选）

需要时**追加**下列任一采集项，不要重发表单：

| 缺什么 | 怎么补 |
|---|---|
| 舌象 | 请用户上传舌苔照片（DSH 附件原生支持，自然光下、不刷舌苔、伸舌 10 秒） |
| 腹诊/脉象 | 说明需面诊，不要求用户自测脉象（自测不可靠） |
| 女性经带 | 问周期、量、色、质、有无痛经 |
| 小儿 | 问喂养、二便、睡眠、有无发热惊厥史 |

### 3. 结构化落盘

采集结果写入预问诊记录（见 `nhx-clinic`）：

```json
{
  "history": { "ten_questions": { "寒热": "...", "出汗": "..." } },
  "tongue_image_ref": "att-xxxx | null",
  "flags_for_physician": ["需确认是否需线下脉诊"]
}
```

### 4. 进入分析

采集齐备后交接给 `nhx-bianzheng` 出辨证卡。
若用户要求医师确认，交接给医师队列（`src/nhx_clinic/review.py`）。

## 完成判据

- 十问**至少覆盖 8 问**，缺项明确标注「未采集」而非留空。
- 用户已明确描述的项**不重复追问**。
- 信息不足时**追问**，不硬出结论。
- `flags_for_physician` 至少 1 条——写清哪些是不确定、必须医师判断的。

## 注意

- 不要求用户自测脉象：自测不可靠，会污染辨证。
- 不问与当下主诉无关的隐私项（最小必要，红线 R7）。
- 采集到的健康信息按敏感个人信息处理，不外流。
