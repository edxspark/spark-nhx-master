## 3. 本次新增能力

### 3.1 视频/音频资源管理界面

```bash
python3 src/nhx_media/server.py     # → http://127.0.0.1:8788
```

零依赖（Python 标准库 + 原生 JS），四个标签页：

| 标签页 | 功能 |
|---|---|
| 总览 | 条目/时长/体积统计、成本估算、多码率档位对比 |
| 资源清单 | 类型/系列/状态/关键词筛选；编辑条目与章节标注 |
| 校验 | 全库完整性检查 |
| 合规 | 按授权状态批量下架 |

**代码强制的闸门**：条目必须齐备 `oss_key` + `duration_sec` + ≥1 个 `segment` 才能上线；
章节不得重叠或超出时长；批量下架必须指定条件（防误伤全库）；路径穿越已阻断。

**种子数据来自实测**：943 条（人纪 317 / 天纪 170 / 音频 456）。
其中**发现站方声明的两处不一致**并记录在案（针灸称 78 集实测 63；内经称 75 集实测 80）。

**成本洞察**（界面自动给出）：按 720p 全量约 494 GB，
存储约 ¥59/月，而 **1000 次全片播放的 CDN 流量约 ¥9.9 万**——
流量是存储的 1600 倍。这直接决定分发策略必须用 HLS 分片 + 签名 URL。

### 3.2 医师闭环

```
L2 回答 → 用户选择「请医师确认」 → AI 结构化预问诊
        → 预问诊报告（标注未确认） → 医师审核 → 医师意见（署名）
        → 合并交付：AI 报告 + 医师意见
```

**七条不变量由代码强制**（不是文档约定）：

| # | 不变量 | 违反后果 |
|---|---|---|
| I1 | AI 不能自己置为 `reviewed` / `referred` | 抛 `InvariantViolation` |
| I2 | 署名状态必须带 `physician_id` + `license_no` | 抛异常 |
| I3 | 未确认不可交付用户 | 抛异常 |
| I4 | 每次流转写审计（谁/何时/依据） | 自动记录 |
| I5 | `needs_more` 不能空转 | 抛异常 |
| I6 | 终态不可再流转 | 抛 `InvalidTransition` |
| I7 | 预问诊报告必须带免责说明 | 抛异常 |

**核心洞察**：AI 的价值不是替代医师，而是把医师 15 分钟问诊压缩成 3 分钟结构化阅读。
若成立，同样人力可服务 3 倍用户——这是商业模式成立的算术基础。

**政策约束**：互联网诊疗**不得首诊**。因此闭环定位为「复诊与健康管理」，
首诊只做就医引导（详见设计文档 §6）。

## 4. 关于授权决策的记录方式

你判定汉唐内容为公开资源、无版权。我照此执行，但**在台账里保留了证据对照**：

| 记录项 | 内容 |
|---|---|
| **权利人声明证据** | hantang.com 版权页（2011-03-22）「轉載須經同意」；页脚「未授權任何中國大陸公司」 |
| **决策方立场** | 判定为公开资源 |
| **台账状态** | `主张公开`——记录**决策方主张**，而非独立法律结论 |
| **保留的工程要求** | 每份文件记 `source_url` + `fetched_at`；支持按来源批量下架；署名保留 |

这样做不阻碍任何开发，但让决策**可追溯、可复核**。若日后权属主张变化，
台账能立刻回答「哪些内容、来自哪里、何时入库、依据什么决策」。

**三项仍为禁止使用**（不受该决策覆盖）：
网盘 405 GB 转载合集（来源不合法）、无 License 的第三方提示词（与倪师内容无关）、
可回源的官网镜像副本（用原站即可）。

## 5. 本次发现并修复的 5 个真实 bug

全部有回归测试锁定，防止复发。

| # | 模块 | Bug | 影响 |
|---|---|---|---|
| 1 | `nhx_schema` | 附子.json 的 `original_text` 放错层级 | 校验器抓出，揭示 Schema 不一致 |
| 2 | `nhx_media` | **上线闸门校验了「当前状态」而非「目标状态」** | published 专属规则永不触发 → 不完整条目能上线 |
| 3 | `nhx_media` | `set_segments` 未校验重叠/越界 | 坏章节数据能写入 |
| 4 | `nhx_media` | **音频套用了视频码率** | 音频体积高估约 12 倍（238.9 GB → 20.4 GB） |
| 5 | `nhx_clinic` | `assign` 未持久化医师；`.get(k, {})` 值为 None 时崩溃 | 「谁在处理」丢失 |

> bug 2 和 4 是**我在浏览器/API 实测中发现的**，不是靠读代码想出来的。
> 这与 `AGENT.md` §7「先证据后结论」一致：跑起来看，而不是声称成功。
