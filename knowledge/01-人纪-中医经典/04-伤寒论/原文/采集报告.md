| 用字 | 说明 |

| 讝 / 谵 | 「讝语」「谵语」两种写法 |

## 4. 两个必须说明的文本学问题

### 4.1 句读（断句标点）随版本而异

**例**：第 3 条

| 来源 | 文本 |
|---|---|
| 本次采集来源 | 太阳病。或已发热。或未发热。**必恶寒体痛呕逆**。脉阴阳俱紧者。名为伤寒。 |
| 通行标点本 | 太阳病。或已发热。或未发热。**必恶寒。体痛。呕逆**。脉阴阳俱紧者。名为伤寒。 |

**字完全相同，只是断句不同。**

**处理**：导入时保留来源句读；跨版本比对用 `normalize_for_compare()` 去标点后进行，
避免把排版差异误判成文本差异。

### 4.2 简繁字形：不做自动转换

**本库以简体落盘，且不做简繁转换。**

古籍传本是繁体，自动 简→繁 会踩「**一简对多繁**」：

| 简体 | 可能是 | 风险 |
|---|---|---|
| 干 | 干 / 乾 / 幹 | 「干姜」应作「乾薑」，转成「干」即错 |
| 里 | 里 / 裏 | 「里急」应作「裏急」 |
| 发 | 發 / 髮 | 「发汗」是「發」，「头发」才是「髮」 |
| 后 | 後 / 后 | 「后」与「後」不同 |

转错**就是篡改原文**，直接违反红线 R1。

**处理**：如实标注 `script: "simplified"`，并说明原因。
若日后取得可信的繁体底本，**另存一份繁体层**，而不是靠程序转换。

## 5. 数据结构

```json
{
  "book": "伤寒论",
  "edition": "赵开美翻刻宋板（明万历二十七年据北宋元祐三年小字本）",
  "script": "simplified",
  "script_note": "……不做简繁转换的原因……",
  "license_status": "公有领域",
  "source": { "primary": {...}, "cross_check": {...}, "tertiary": {...} },
  "verification": { "exact_match": 339, "minor_variant": 45, "divergent": 14 },
  "textual_notes": [ {句读问题}, {简繁问题} ],
  "coverage": { "total": 398, "collected": 398, "missing": [], "duplicates": [] },
  "articles": [
    {
      "no": 12,
      "text": "太阳中风。阳浮而阴弱。……桂枝汤主之。",
      "section": "辨太阳病脉证并治（中）第六",
      "formulas": ["桂枝汤"],
      "verification": "verified",
      "raw_text": "12、太阳中风。……$f{桂枝汤}主之。"
    }
  ]
}
```

**字段说明**：

- `text` — 可读正文（标记已剥离、条号已去除）
- `raw_text` — **原始文本（含标记）**，供审计回溯。红线 R1 要求可追溯，这一字段是保障。
- `formulas` / `herbs` / `annotations` — 从 `$f{}` / `$u{}` / `$a{}` 标记解析而来
- `verification` — 交叉验证等级
